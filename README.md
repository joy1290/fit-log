# FitLog

FitLog is a modern workout library and training planner built with Next.js. It allows users to explore workouts, view detailed exercise information, create a daily workout plan, save workouts for later, and track completed exercises.

## ✨ Features

### 1. Workout Library
Browse a collection of workouts covering different muscle groups and equipment.

### 2. Workout Details
View workout images, descriptions, equipment, difficulty, sets, reps, duration, calories, rating, and instructions.

### 3. Today's Plan
Add up to five workouts to today's training plan and monitor total exercises, minutes, and calories.

### 4. Saved Workouts
Save workouts for later and manage them from the Saved tab.

### 5. Workout Completion
Mark workouts as completed and keep the completed state after page reload.

### 6. Sorting
Sort workouts by duration, calories, or rating.

### 7. Responsive Design
The application works across mobile, tablet, and desktop screen sizes.

### 8. Local Storage
Today's plan and saved workouts persist after refreshing the browser.

## 📂 Main Routes

- `/` — Workout Library
- `/workouts/[id]` — Workout Details
- `/my-plan` — Today's Plan and Saved Workouts
